How to use these prototypes

Each screen is a self-contained HTML file using Fluent UI v9 design tokens (Teams Dark theme). Open each file in a browser to see the full interactive prototype. Use these as pixel-perfect references when building your Figma frames.

Design tokens: All colors, spacing, typography, and border-radius values use CSS custom properties matching Fluent UI v9 naming. Resize the browser window below 768px to see the mobile responsive layout.

Coverage: 5 screens (4 unique + 1 phase variant) across 5 Epics (F2–F6). Exceeds the university requirement of minimum 4 unique screens.
